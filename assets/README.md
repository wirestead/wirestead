# wirestead brand assets

The **square bracket mark** is the current visual identity. It depicts three
transport paths converging within stable software-wrapper brackets. The symbol
is a balanced 1:1 shape; the visual wordmark is lowercase `wirestead`.

## Current vector assets

| File | Use |
| --- | --- |
| `wirestead-mark.svg` | Transparent 1:1 standalone symbol |
| `wirestead-mark-monochrome.svg` | Monochrome 1:1 symbol |
| `wirestead-icon-dark.svg` / `wirestead-icon-light.svg` | Square GitHub / app avatars |
| `wirestead-favicon.svg` | Dark badge / favicon |
| `wirestead-logo-square.svg` | Stacked square symbol and wordmark |
| `wirestead-logo-horizontal.svg` | Primary README logo on light backgrounds |
| `wirestead-logo-dark.svg` | Primary README logo on dark backgrounds |
| `wirestead-logo-monochrome.svg` | Monochrome horizontal logo |

All current SVGs contain vector paths and use no external font dependencies.
See [`brand/Wirestead-brand-guide.md`](brand/Wirestead-brand-guide.md) for
identity, color palette, and usage rules.

## Raster exports and sources

PNG exports are regenerated from the current SVGs for horizontal lockups,
mark (512 px), and favicons (64 px and 512 px). The 1:1 square stacked logo and
dark/light avatar badges also have PNG exports. Editable source SVGs live in
`brand/` and match the current production vectors. Older brand-board images
are historical proposals, not approved artwork.

External documentation images, charts and repository-specific diagrams should
remain in their respective repositories.
